# Logos EPG BR

Cards 512×512 (fundo na cor da marca, logo centralizado) usados como `<icon>` no EPG publicado em https://vinnyoliveira.github.io/epg-br/.

- `logos/<canal>.png` — card por canal (mesmo ID do EPG)
- `index.html` — galeria

Gerado por `scripts/make_logo_cards.py` no repositório de origem.
